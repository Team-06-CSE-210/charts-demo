Vanilla charts

Two chart types, plain JavaScript, and SVG. Resize the window to see the charts adapt.

Add coordinates

Add a point to both charts. The line connects points in the order you add them.

Showing sample A.

const chart = new VanillaCharts.Chart('#scatter', {
  type: 'scatter',
  data: [[0, 2], [1, 4], [2, 3]],
  xLabel: 'Time',
  yLabel: 'Value'
});

chart.update([[0, 3], [1, 5], [2, 4]]);
chart.destroy();
